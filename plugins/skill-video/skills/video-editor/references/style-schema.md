# The style: `.style/style.json`

The style is **who the user is and what their videos look and sound like**. Each project has its own: it lives in
`.style/` at the root of the projects folder (the project Claude Code runs in, next to the videos), never in the
plugin, whose updates replace its folder:

| File | |
|---|---|
| `style.json` | The truth. Change it with `video.mjs style set <path>=<value> …` and `style note "<text>"` only |
| `STYLE.md` | Its readable form, regenerated by every `style` command. Read it, never edit it |
| `fonts/`, `avatar.png`… | Files the style points at (paths relative to `.style/`); `init` copies the whole folder into the project's `source/` |
| `site/` | What `video.mjs site <url>` saw of the brand's site: `screen-NN.jpg`, `svgs.jpg` and `svg-NN.svg`, `site.json` (colors ranked by surface, fonts, images). It stays here: `init` does not copy it |

Each project copies `style.json` at `init` (`source/style.json`, and `source/STYLE.md`): a later change of style
never changes a project already made. To bring a project up to date on purpose, copy the two files again.

Any field left out takes the engine default below. `style set` parses a value as JSON when it can (`-21`, `true`,
`["a","b"]`), otherwise keeps it as text (`#2563eb`, `@pab`). Quote values with spaces:
`style set creator.name="Pierre Alain" creator.cta.button="S'abonner"`.

| Path | Default | |
|---|---|---|
| `creator.name` | `""` | Name shown in the CTA |
| `creator.handle` | `""` | `@handle` |
| `creator.lang` | `"fr"` | Language of captions, titles, CTA, numbers (`11 726`, `106,3`) and of the talk with the user |
| `creator.niche`, `creator.audience` | | What the channel is about, who watches: they steer tone and examples |
| `creator.avatar` | `null` | An image of `.style/` (`avatar.png`), for CTA cards; in a project it is `source/<file>` (in the scene: `` `project/source/${style.creator.avatar}` ``) |
| `creator.cta.sub` | `""` | The CTA's line under the name ("L'IA pour les devs") |
| `creator.cta.button`, `creator.cta.done` | `"S'abonner"`, `"Abonné"` | The subscribe button, before and after the click |
| `look.palette.paper` | `#f2ede3` | The light field (`var(--paper)`) |
| `look.palette.ink` | `#171512` | Text (`var(--ink)`) |
| `look.palette.accent` | `#2563eb` | The accent (`var(--accent)`) |
| `look.palette.muted` | `#857e72` | Secondary text (`var(--muted)`) |
| `look.palette.card` | `#fffdf8` | Cards (`var(--card)`) |
| `look.palette.<name>` | | Every other color of the brand, named by its role: `coal` (its dark field), `cream`, `accent-dark`… Each one is `var(--<name>)` in the scene. Take the whole palette the brand uses |
| `look.font` | `"Inter"` | Font family of the videos (`var(--font)`); Inter ships with the engine |
| `look.fonts` | `{}` | Every family with its file, the main one included: `{ "Clash Display": "fonts/clash.woff2" }`, files in `.style/fonts/` |
| `look.symbols` | `[]` | The brand's recurring graphic devices, in words: `["the logo's hexagon: bullets, separators, outlines", "buttons prefixed with « / »"]`. Material for each video's motif, not a direction |
| `look.paper.grain`, `.relief`, `.depth` | `1.2`, `1`, `1.7` | The texture `paper()` draws, only when the user wants a paper look: grain (0 = flat), embossing, shadow depth |
| `look.captions.size` | `84` | Caption size, px on the 1080 canvas |
| `sound.music` | `-21` | Under a voice: loudness of the music bed (LUFS), before ducking. Without a voice, `sound.py` sets its own balance. Every mix ends at -14 LUFS |
| `sound.sfx` | `-28.5` | Under a voice: loudness of the effects (LUFS) |
| `sound.duck` | `0.5` | The music's gain drops by this share while someone speaks (0.5 = half) |
| `notes` | `[]` | What the user asked for, in their words: rules learned from feedback ("display type always overflows the frame"), a look they liked, the sound identity ("warm electronic music, 110–120 bpm, glassy effects"). Every video follows them, so never a direction you chose yourself |

What is not here: how to edit (cuts, pace, captions on or off, motion density) belongs to the rule packs
(`rules-format.md`), and how one video looks belongs to its Direction in About.md.

## The setup interview

For a brand, run `video.mjs site <url>` first and read what it saved: the palette, fonts, logo and symbols come from
there. Otherwise ask in the user's language, a few questions at a time (AskUserQuestion where the answers are
choices), and offer sensible defaults: name and handle; language; niche and audience; CTA line and button texts;
palette (propose two or three palettes, or take their brand colors); font (Inter, or a file they give, or a free font
you download into `.style/fonts/`); the mood of the music, in their words. Then one `style set` with every answer, a
`style note` per preference they stated, and show the resulting STYLE.md.
